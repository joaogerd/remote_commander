CONFIGURAÇÃO

Segurança

O painel só escuta em 127.0.0.1. Para acesso pelo celular, publique o serviço apenas na sua tailnet com Tailscale Serve e HTTPS.

  • Acesso à API exige token de 256 bits.
  • Arquivos ficam limitados ao workspace; diretórios de credenciais conhecidos são bloqueados.
  • Gravação e execução exigem habilitação explícita na inicialização.
  • A IA local pede aprovação humana para operações com efeitos.
  • Executar Python ou Git não é uma sandbox: o processo recebe os privilégios do usuário Linux.
  • A integração MCP via stdio executa ferramentas já habilitadas sem a confirmação do painel web.

Beta experimental. Não utilize em estações institucionais, redes públicas ou dados sensíveis sem autorização e auditoria apropriadas.
