# Changelog

## 0.1.0-beta — 2026-11-18

- Primeira beta do painel web responsivo, autenticado e restrito a loopback.
- Operações de arquivo restritas ao workspace, com escrita opt-in.
- Execução de programas com allowlist, timeout e autorização explícita.
- Integração Ollama local, com aprovações pendentes para escrita e comandos.
- MCP local via stdio, comandos somente leitura por padrão.
- Auditoria básica sem conteúdos, documentação de Tailscale e testes.
